# Packages for running ARoG on Windows with Python 3.10.
#
# Install with (from the ARoG-main folder, inside the "arog" conda environment):
#     pip install -r demo_kit\requirements_windows.txt
#
# Why not the authors' requirements.txt?
#   It lists 148 packages, including vllm and ray, which only install on Linux and are not
#   needed when the language model is OpenAI. Installing it on Windows fails part way.
#   This file keeps the authors' exact versions for every package their code imports, and adds
#   four that their code imports but their list forgot (httpx-socks, nltk, requests, tqdm).
#
# torch from the normal package index is the CPU version on Windows. That is what we want:
# the embedding model is small and the laptop's 2 GB graphics card is not needed.
